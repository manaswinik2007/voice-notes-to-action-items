# Voice Notes to Action Items

A web-based application that converts voice notes into structured action items using Whisper speech recognition and rule-based NLP.

## Features

- Voice recording
- Speech-to-text transcription using Whisper
- Automatic action-item extraction
- Person, task, deadline, and priority detection
- Search and filter tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- Export tasks as CSV
- Local storage for saving tasks

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Whisper
- Rule-based NLP

## Project Flow

Voice Input → Whisper Transcription → Action Item Extraction → Dashboard

## Note

AI-generated transcription and extracted results may not always be perfect. Please review the results before taking action.
